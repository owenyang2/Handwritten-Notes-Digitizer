# Web workspace

Mode: Operate. Confirmed scope: web first, focused research workspace,
code-first implementation. Native iPhone/iPad is outside this change.

## Direction contract

**THESIS:** A research folio keeps each correction attached to its original.

**OWN-WORLD:** Warm paper around a notebook surface, forest-green controls,
serif screen headings and Geist interface text. At night the same structure
uses warm charcoal and soft green. The user requested this cozier treatment
and more obvious selections after seeing the initial cool design. Real handwriting carries the visual
character; the shell supplies order.

Use “[username]’s notebook” as the signed-in name, with “Notebook” before
sign-in. Copy explains actions and states; omit slogans and decorative workspace
labels. Hide empty recent navigation and keep one desktop collapse control.
Section navigation stays in the sidebar. The toolbar only adds a Library
breadcrumb inside a notebook, providing a real return action.
Avatar/name share a row; Log out has a separate icon row, using the navigation
icon/text columns. Keep the shell and recents stable during collection changes,
retain warm views, and commit loaded review pages together. Routine navigation
uses brief color feedback without fading the whole page.

**STORY:** Locate notebook → compare source/result → correct → explicitly save
→ export. Error recovery and training consent remain deliberate choices.

**FIRST VIEWPORT:** Product and workspace navigation frame a named Library.
Search, archive/trash scope, shelf/list controls and an honest loaded count
precede real notebook previews. A single notebook occupies a full shelf;
multiple notebooks form equal columns. Review begins with notebook title,
compact page/conversion controls and paired original/result panes. On phones,
the selected crop sits above the correction, with Original/Result switches.

**FORM:** An inset sheet and flat structural borders; 44px controls; simple
opaque overlays. Menus move briefly without fading their text. Thumbnail
movement supplies pointer feedback. Reduced motion removes travel. Preserve
drafts while switching routes, panes, appearance and layout.

**SIGNATURE:** Selecting a recognized region connects its source outline,
original crop and editable text. No decorative animation delays that action.
Theme is visible on the sign-in screen and in the workspace toolbar. Active
navigation has a clear outline; grid/list and phone-pane selections use a
filled control, with semantic selection states preserved.

## Direction evidence

Taste Skill dealt **Achromatic ledger**, seed **244730145**. Its neutral
chrome, Geist face and color reserved for the main evidence suit long review
sessions. The existing notebook navigation remains because recent notebooks
and account controls are necessary; the no-sidebar suggestion is not adopted.

Impeccable direction seed **488841eb** assigned the sixth grounded direction,
research folio. The grounded set spanned research indexes, archive finding
aids, journal proofing, optical proofreaders, accession catalogs, research
folios and seminar capture desks. The user-pinned research-workspace brief
constrains the result. Challenger systems were considered against task clarity
and audience identification: variable-font specimen, streaming wall, Metro
tiles, centre-rail reference setting, boarding-pass board and construction-grid
specimen. All were declined: ornamental scale, focus expansion, unfamiliar
controls, wide margins, live ranking or visible construction would displace
the source/editing task. Their useful disciplines are immediate feedback,
recognizable real previews, explicit hierarchy, aligned evidence, retained row
identity and consistent grid geometry; those raise the folio without importing
their motifs. No challenger or generated comp is the build target.

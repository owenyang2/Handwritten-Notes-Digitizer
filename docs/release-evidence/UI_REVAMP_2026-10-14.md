# Quiet Notebook implementation — October 14, 2026

The later [final verification and Ponytail audit](VERIFICATION_AND_PONYTAIL_AUDIT_2026-10-14.md) resolves the Tools-menu/page-action failures recorded below and records green complete iPhone/iPad native suites. Earlier sections retain their original source and acceptance scope.

The web app now opens in Library, with a React workspace, responsive notebook navigation, System/Light/Dark appearance, and the existing API and persistence contracts. Native SwiftUI keeps PencilKit and adopts matching appearance and adaptive review. This is implementation evidence, not a production-readiness or recognition-accuracy claim.

The complex DOM review modules intentionally remain isolated migration hosts. They exclusively own their descendants; React owns navigation and their parent hosts. No new state-management layer, rich-text editor, recognition engine, or backend schema was introduced.

## Baseline and verification

Before changes, the production build and all 175 frontend tests passed. The previous interface started with recognition/calibration, while the new default is Library. The existing source/stale-review, export-revision, sync, upload-queue, and native ink contracts were reused.

- Frontend: TypeScript/production build and the existing domain/property tests, with the removed Gallery tests replaced by React Library checks.
- Browser checks: production-build import → source selection → correction → export; dirty draft retention across region/phone/theme changes; conflict comparison; deep link/back; System appearance and override persistence; failed import retry and dialog focus restoration. Layouts cover 320, 640, 1024, and 1440 CSS pixels in both appearances.
- Browser fixtures are explicitly synthetic and exercise real HTTP response shapes. They do not establish recognition quality, field performance, or hardware keyboard behavior.
- Live local API: isolated temporary database/object store and a synthetic PDF. Browser import, server crop creation, source-linked correction, Save review, reload, and Markdown download passed. The downloaded file contained the saved correction. No training consent was granted. [Machine-readable evidence](ui-revamp/live-api-evidence.json).
- Native: 30 shared Swift package tests passed; the universal app compiled against the iOS simulator SDK. All 33 native app tests passed on iPad Pro 11-inch (M4), iOS 18.6, including ink commit recovery, Pencil canvas sync, archives and exact export dimensions. Two iPad UI tests passed: persisted appearance after relaunch and offline notebook creation/relaunch.
- Production dependency audit: zero known advisories after updating KaTeX to the patched 0.18.2 release. The pre-existing Vite/Vitest development dependency advisories are separate from the production bundle and are not represented as resolved.

# iOS foundations (partial)

`PersonalizedNotesKit` is an early shared package for the future iPad client:

- `ink_v1` serialization helpers
- API DTOs / HTTP client sketch
- Keychain session helpers
- SQLite local store
- pending-operation sync engine sketch

It is **not** a finished iPad application. There is no SwiftUI shell, `PKCanvasView`,
Xcode app target, share extension, or simulator test suite yet. Treat this directory
as reviewed source foundations that still need an application target and golden tests.
